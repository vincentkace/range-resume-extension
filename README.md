# 接着下 · 换链接续传

Chrome / Edge 的 Manifest V3 扩展。把 HTTP 文件按 8 MiB 分块保存到用户选择的本地目录；断网或 Cloudflare Quick Tunnel 网址变化后，在原任务中填写新文件网址继续。无服务器、无运行时下载依赖、无遥测。

## 安装

1. 解压交付 ZIP。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的 `extension` 文件夹。
5. 点击扩展图标，打开下载管理器。

需要允许扩展安装、本地目录选择/写入和目标网址访问的桌面版 Chrome / Edge。企业沙箱可能禁止其中一些能力；扩展不能绕过沙箱的网络、文件或安装策略。浏览器至少 Chrome 109，并建议使用当前受支持版本。

## 使用

1. 粘贴具体文件的网址，不是目录首页；可填入发送方给出的完整 SHA-256。
2. 点击“授权并检查链接”，仅授权所输入网址的站点。
3. 点击“选择保存目录并下载”。扩展在目录下建立 `续传下载-xxxxxxxx` 子目录，包含 `resume-task.json` 和 `blocks` 文件夹。
4. 下载过程中保持管理器标签页打开。暂停、断网、关闭标签页或浏览器后，已经完整提交的块保留；未完成的一块最多重下 8 MiB。
5. 换隧道地址时，在同一个任务的“当前文件网址”中填入新文件网址，点击“继续下载”。
6. 完成后点击“导出并校验文件”，选择最终文件保存位置。提供预期 SHA-256 时，校验失败将中止导出，不提交新文件内容。

浏览器重启后会恢复任务列表；可能需要重新授权本地目录。若扩展被重新安装、浏览器数据被清空或换了电脑，点击“导入任务目录”并选择原来的 `续传下载-xxxxxxxx` 子目录即可恢复。该目录可以复制到其他电脑。

预期 SHA-256 只填 64 位哈希，不含文件名。对于本次 Paddle wheel 分片，分别填 `SHA256SUMS.parts` 对应行的哈希。

## 续传与校验边界

- 每个 HTTP 请求必须返回符合请求范围和文件总大小的 `206`；忽略 Range、跳转登录页、范围错误、压缩转换或版本变化时停止。
- 换链接会比较文件总大小、首尾 64 KiB 的 SHA-256、双方可用的 ETag / Last-Modified，并重新获取最后一个已保存分块核对 SHA-256。
- 抽样不能证明整个远端文件完全相同。要验证最终文件，应提供发送方的预期 SHA-256；没有预期值时仅显示计算结果，不宣称文件已通过来源校验。
- 任务目录是恢复依据。下载完成后，导出会重新校验所有本地块，再以流式 SHA-256 合并，内存用量不会随文件大小线性增加。
- 导出时浏览器可能使用临时文件。任务块与最终文件需要约两倍文件大小的可用磁盘空间。
- 只从本扩展创建的任务开始续传；不自动接管 Chrome 的 `.crdownload` 或其他下载器的部分文件。
- 不支持需要登录 Cookie 或交互登录的文件站点，不跟随 HTTP 跳转。公共 Cloudflare Tunnel + RangeHTTPServer 链接适用。
- 关闭管理器标签页会终止当前请求；扩展不会在浏览器关闭后后台下载。完成的块可以继续。
- 同一浏览器内通过 Web Locks 防止多个标签页同时写同一任务。不要从两个浏览器/浏览器配置同时操作同一磁盘任务目录。

## 本地数据与权限

没有默认授予任意站点访问权限。扩展只在用户点击按钮时请求指定 HTTP/HTTPS 站点权限；不读取网页、Cookie 或浏览历史。

IndexedDB 保存任务列表及用户授权的目录句柄。任务目录保存网址、文件信息、预期哈希和各块哈希；网址中的查询参数也会保存在记录中，请像对待下载链接一样保管任务目录。扩展不将这些记录发送到其他服务。

“移除列表记录”只删除浏览器列表项，不删除磁盘文件。完成并核对最终文件后，可手动删除对应 `续传下载-xxxxxxxx` 目录释放空间。

## 文件服务示例（发送方 Windows CMD）

```cmd
cd /d D:\file_transfer
python -m RangeHTTPServer --bind 127.0.0.1 8010
```

另开窗口：

```cmd
cloudflared.exe tunnel --url http://127.0.0.1:8010
```

接收方在扩展里填写 `https://生成的地址.trycloudflare.com/具体文件名`。隧道无需将 8010 作为公网入站端口开放；接收端必须能访问该 Cloudflare 地址。

## 开发与构建

运行时为无依赖的原生 JavaScript。Node.js 测试只使用内置模块；Playwright 仅用于浏览器验收。

```sh
npm test
npm run build
```

浏览器测试：先 `npm install`、`npx playwright install chromium`，再 `npm run test:browser`。可通过 `RESUME_TEST_CFT` 指定 Chrome for Testing 可执行文件路径。浏览器测试在独立临时配置中加载真实扩展；原生选择器/授权提示通过测试桩交互，文件读写使用浏览器的实际 OPFS 和 IndexedDB，覆盖页面重开及整个浏览器重启。最终使用者仍需要在自己的环境中完成原生授权。

构建固定输出到工作区 `artifacts/range-resume-extension/extension`。本地测试状态和浏览器配置保存在 `.local/wendi`。测试包含断网、不完整响应、换地址续传、错误 Range、源文件变化、本地数据损坏、错误最终哈希和空文件。
